CloudGuard — SOC Simulator

          

            A self‑hosted Security Operations Center built during a 3‑month academic internship.
            A Wazuh SIEM runs on a DigitalOcean droplet, monitoring Windows 11 and Ubuntu endpoints
            over Tailscale. Shuffle SOAR automates the response and pushes alerts to a Telegram bot.
          

          
    
            
  • Custom Wazuh rules mapped to 7 MITRE ATT&CK techniques: SSH brute force, sudo abuse, FIM with SHA256, port scans
    • 
            
  • 4 end‑to‑end SOAR playbooks with VirusTotal, AbuseIPDB and Fail2ban auto‑blocking
    • 
            
  • Delivered with a Lab Guide and SRS document, bi‑weekly supervisor check‑ins and a final presentation
    • 
          

          
My part: led the two‑person team — lab architecture, planning and reporting,
            detection rules and playbooks, and the documentation that shipped with it.

LogAnalyzer

          

            A Python tool that detects SSH brute‑force attacks from Linux auth.log files.
            It aggregates failed logins by IP, tracks which accounts are targeted, and prints a ranked
            table of offenders. The engine is decoupled so it runs as a CLI, a pip‑installable library,
            or behind a Vue 3 drag‑and‑drop dashboard.
          

          
$ python cli.py auth.log
✔ parsed 2,418 lines
! 203.0.113.7   failed ×142  → root, admin
! 198.51.100.3  failed ×61   → ubuntu

          

            PythonVue 3TypeScriptPiniaLinux logs
